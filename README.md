# Taisa Atelier API

Sistema de agendamentos para salão de beleza.

## Descrição

API desenvolvida em Node.js + Express + TypeScript para gerenciar agendamentos de serviços em um salão de beleza.

## Funcionalidades

- Listagem de serviços disponíveis
- Criação de agendamentos
- Listagem de agendamentos

## Tecnologias

- **Node.js**
- **Express**
- **TypeScript**
- **CORS**

## Como executar

```bash
# Instalar dependências
npm install

# Executar em desenvolvimento
npm run dev
```

## Endpoints

- `GET /` - Teste da API
- `GET /services` - Listar serviços disponíveis
- `POST /appointments` - Criar novo agendamento
- `GET /appointments` - Listar todos os agendamentos

## Porta

O servidor roda na porta `3333`.
